03

Press play

Your linked Spotify account and lyrics appear automatically.

For developers

Build it from source

Clone the repo and run it locally with Node.js 20 or newer.

git clone https://github.com/selfsecuredlab/lyrics-status.git
cd lyrics-status
npm ci
npm start
